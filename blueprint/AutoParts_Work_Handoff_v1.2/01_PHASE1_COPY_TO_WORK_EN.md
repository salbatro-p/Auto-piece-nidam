## Reliability is NON-NEGOTIABLE
- Use DB constraints, ACID transactions, row-level atomic conditional stock updates/appropriate locking, consistent ordering for multi-SKU operations, deduplication/idempotency, bounded retries and predictable reservation expiry.
- Payments, shipping, import and catalog sync must never directly modify stock without the inventory domain service.
- Production inventory must not depend on an external supplier API, spreadsheet, browser session or AI model being available at checkout. External integrations are asynchronous with timeouts/circuit breakers and failure queues.
- Error/incident logging, request tracing, health checks, backup and verified restore, multi-environment separation, secret management, rate limits, observability and runbooks are mandatory.
- Follow OWASP ASVS controls proportionate to the risk, validate authorization on every API call, sanitize upload/import inputs and prevent IDOR and data leaks.
- Run security, permission, full AR/FR/EN translation/top-bar switcher/RTL and mid-workflow locale-change tests, accessibility, concurrency, mobile, data integrity, failure injection and load tests described in `04_QA_SLOS_AND_RELEASE_GATES_EN.md`.
- Do NOT claim no bugs. Quantify observed error/latency rates and explicitly document remaining risks, environment limits and untested conditions.
